# Retail_Customer_Behavior_analysis

End-to-end analysis of 3,900 customer transactions using **Python, PostgreSQL, and Power BI** — covering data cleaning, feature engineering, SQL-based business analysis, and an interactive dashboard for revenue, subscription, and customer segment insights.

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from 3,900 purchases across multiple product categories. The goal is to uncover insights into spending patterns, customer segments, product preferences, and subscription behavior to guide strategic business decisions.

The workflow spans the full data pipeline: cleaning and feature engineering in Python (Pandas), structured business-question analysis in PostgreSQL (SQL), and an interactive Power BI dashboard for visualizing revenue, sales, and customer segments.

## 🛠️ Tech Stack

- **Python** (Pandas) — data cleaning, feature engineering
- **PostgreSQL** — SQL-based business analysis
- **Power BI** — interactive dashboard & visualization

## 📊 Dataset Summary

- **Rows:** 3,900
- **Columns:** 18
- **Key Features:**
  - Customer demographics (Age, Gender, Location, Subscription Status)
  - Purchase details (Item Purchased, Category, Purchase Amount, Season, Size, Color)
  - Shopping behavior (Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases, Review Rating, Shipping Type)
- **Missing Data:** 37 values in the Review Rating column

## 🧹 Data Preparation & Cleaning (Python)

- **Data Loading:** Imported the dataset using `pandas`
- **Initial Exploration:** Used `df.info()` and `.describe()` to check structure and summary statistics
- **Missing Data Handling:** Imputed missing values in `review_rating` using the median rating of each product category
- **Column Standardization:** Renamed columns to snake_case for readability and documentation
- **Feature Engineering:**
  - Created `age_group` column by binning customer ages
  - Created `purchase_frequency_days` column from purchase data
- **Data Consistency Check:** Verified `discount_applied` and `promo_code_used` were redundant; dropped `promo_code_used`
- **Database Integration:** Connected Python script to PostgreSQL and loaded the cleaned DataFrame for SQL analysis

## 🗄️ Data Analysis (SQL / PostgreSQL)

Structured analysis in PostgreSQL to answer key business questions, including:

1. **Revenue by Gender** — Compared total revenue generated by male vs. female customers
   - Male: $157,890 | Female: $75,191
2. **High-Spending Discount Users** — Identified customers who used discounts but still spent above the average purchase amount ($59.76)

## 📈 Power BI Dashboard

Built an interactive dashboard featuring:

- **KPI cards:** Average Review Rating (3.75), Average Purchase Amount ($59.76), Number of Customers (3.9K)
- **Slicers:** Subscription Status, Gender, Category, Shipping Type
- **Visuals:** % of Customers by Subscription Status, Revenue by Category, Sales by Category, Revenue by Age Group, Sales by Age Group

## 💡 Key Insights

- Male customers generated over 2x the revenue of female customers ($157,890 vs $75,191)
- Only 27% of customers are active subscribers — a significant opportunity for subscription growth
- A meaningful segment of customers uses discounts while still spending above average, suggesting discounts aren't the sole driver of high-value purchases
- Young Adult and Middle Aged groups drive the highest revenue and sales volume

## ✅ Business Recommendations

- **Boost Subscriptions** — Promote exclusive benefits for subscribers
- **Customer Loyalty Programs** — Reward repeat buyers to move them into the "Loyal" segment
- **Review Discount Policy** — Balance sales boosts with margin control
- **Product Positioning** — Highlight top-rated and best-selling products in campaigns
- **Targeted Marketing** — Focus efforts on high-revenue age groups and express-shipping users
